# Saison Restonica 69

Web app de suivi de saison trail : blocs d'entraînement, courses, semaine en cours à cocher et carnet de renfo.

- `index.html` : la saison
- `renfo.html` : le carnet de renfo (séances, séries, chronos)
- `data.json` : les données réalisées et la semaine planifiée, mises à jour par Claude
- `sw.js`, `manifest.json`, `icon-*.png` : installation sur l'écran d'accueil et usage hors connexion

Sur iPhone : ouvrir le site dans Safari, Partager, « Sur l'écran d'accueil ».
